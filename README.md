\# Logistics \& Fleet Performance Analytics



\## Project Overview



This project focuses on analysing the operational performance of a fictional logistics and trucking company using data analytics techniques.



The objective is to evaluate fleet utilisation, delivery performance, fuel consumption, transportation costs, maintenance activities and driver performance.



The project follows an end-to-end analytics workflow using Python, MySQL and Power BI.



\## Business Objectives



\- Evaluate fleet utilisation and vehicle productivity.

\- Analyse delivery performance and identify delay patterns.

\- Examine fuel consumption and transportation costs.

\- Assess vehicle maintenance expenditure and reliability.

\- Analyse driver performance and safety incidents.

\- Develop actionable insights to support operational decision-making.



\## Technology Stack



\- Python (Pandas, NumPy, Matplotlib, Seaborn)

\- MySQL

\- Power BI

\- Git and GitHub



\## Project Structure



\- `data/` – Raw and processed datasets

\- `notebooks/` – Data exploration and statistical analysis

\- `src/` – Reusable Python scripts

\- `sql/` – Database development and SQL analysis

\- `powerbi/` – Power BI reports and data model documentation

\- `docs/` – Business requirements, data dictionary and diagrams

\- `reports/` – Analysis findings and final reports

\- `tests/` – Data validation and testing



\## Dataset



Source: Kaggle – Logistics Operations Database



The dataset represents simulated trucking and logistics operations. It is used for educational and portfolio purposes and does not represent actual company performance.
